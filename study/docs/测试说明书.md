### 4.2 粒子背景

TC-PERF-04 原记录的 60fps 只反映帧率，不反映渲染是否正确。2026-07-31 抓画布像素复查发现：
`ParticleBg` 在挂载时读到的容器宽度为 0，所有粒子被播撒在原点，引导层 2560×1440 的画布上
全部着色像素落在 `[0,0]–[68,64]` 区间内——即星空效果从未真正出现。改为归一化坐标 +
`ResizeObserver` 后，两块画布的着色范围分别是 `[0,4]–[2472,1320]` 和 `[76,12]–[1992,1384]`，
铺满整幅；同时补上 `prefers-reduced-motion` 降级与后台标签页暂停。

### 6.2 已知限制

1. Demo 阶段使用本地"剧本式"流式回放，未接入真实大模型 API（已预留 Provider 接口）
2. 资源内容基于知识库模板派生，生产部署需对接科大讯飞星火等大模型生成真实内容
3. 学生数据为 Mock 预置，未对接真实数据库
4. 思维导图 25 节点全展开后适配缩放约 0.4，节点字号偏小，因此默认只展开到主分支，
   二级节点点击逐支展开；要在全展开状态下保持可读，需换布局方向或做分层折叠，暂未做
5. `npm audit --omit=dev` 仍报告 React Router 的 2 个 RSC Mode 高危公告。本系统是纯客户端
   `BrowserRouter` SPA，未使用 RSC 或 Server Actions，对应攻击路径未启用；npm 建议的自动
   修复会强制降级并引入破坏性变更，故保留当前版本并记录风险

### 6.3 总体结论

系统**通过全部人工测试用例与 66 项自动化用例**，满足赛题所有功能与非功能需求，可交付演示。
