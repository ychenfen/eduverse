# 智学灵境 EduVerse 决赛就绪报告

> 版本：决赛冲刺版  
> 验收日期：2026-07-31  
> 目标：让评委在 3 分钟内看懂价值、看到技术证据，并亲手验证学习闭环。

## 1. 一句话定位

智学灵境不是把同一份答案换一种说法，而是由 7 个角色化智能体依据学习者画像与真实学习记录，持续重组资源、路径、练习和评估的个性化学习系统。

## 2. 评委应看到的五层证据

| 评审问题 | 产品证据 | 可验证入口 |
| --- | --- | --- |
| 是否真正个性化 | 六维画像保存分数、标签、抽取依据与版本变化 | `/profile?demo=1` |
| 是否真正多智能体 | 7 个角色分工，公开 thinking → generating → validating → done 协作轨迹 | `/workshop?demo=1` |
| 推荐是否可解释 | 24 个知识节点结合画像、掌握度、先修依赖计算状态与推荐理由 | `/path?demo=1` |
| 学习是否形成闭环 | 计划任务进入学习/评估，完成后写回记录、掌握度和计划进度 | `/plan` → `/assessment` |
| 效果是否可追踪 | 指标、雷达图、热力图、薄弱点与调优建议共同呈现 | `/assessment?demo=1` |

## 3. 180 秒决赛演示脚本

1. **0–20 秒：立题。** 从 Onboarding 点击「决赛演示模式」，进入 `/showcase`。用一句话说明：系统优化的不是一次答案，而是每个学生之后的学习过程。
2. **20–55 秒：画像证据。** 点击第一步，展示六维画像、版本与形成依据，强调画像会被学习行为更新，不是静态问卷。
3. **55–110 秒：智能体编队。** 进入资源工坊，现场选择知识点与资源类型，展示角色分工、流式进度和校验门禁。
4. **110–140 秒：路径解释。** 打开学习路径，点击节点，展示掌握度、学习时长、测验结果、先修依赖和推荐原因。
5. **140–180 秒：闭环落地。** 从学习计划进入任务，完成阅读/观看/实践并提交；返回计划页，展示进度从未完成变为已完成，再打开评估说明数据如何驱动下一轮推荐。

现场若时间被压缩，可始终通过右下角引导卡的「下一步」跳转，不依赖讲解员记忆路径。

## 6. 现场启动清单

最省事的方式：解压成品包，直接双击 `index.html`。构建使用相对资源路径，且在 `file://` 协议下
自动切换为 HashRouter，无需任何服务器即可完整演示。

需要跑源码或做验收时：

```bash
npm install
npm run quality
npm run preview -- --host 127.0.0.1
```

打开终端输出的预览地址，首次页面直接点击「决赛演示模式」。如需重置演示状态，访问 `/?reset=true`
（双击打开时为 `index.html#/?reset=true`）。

## 7. 已知外部依赖公告

`npm audit --omit=dev` 仍报告 React Router 的 2 个 RSC Mode 高危公告。当前系统是纯客户端 BrowserRouter SPA，没有使用 RSC 或 Server Actions，对应攻击路径未启用。npm 给出的自动修复会强制降级到旧版并产生破坏性变更，因此本次保留当前版本并记录风险，后续跟进上游正式补丁。
